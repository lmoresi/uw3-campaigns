## Collective-guard scan of the `.pyx` sources (prototype, 2026-11-14)

A review tool for this week, as the dev hub asked. Next week it becomes a test_0052 PR. The code and logs are kept on the review workstation in the run directory `runs/2026-11-14-pyxscan/`:
- `pyx2py.py`: a line-preserving Cython-to-Python pre-pass;
- `pyxscan.py`: test_0052's classifier plus PETSc collectives and the early-exit rule;
- `dev-c2aa36b3.pyx.txt` and `dev-c2aa36b3.all.txt`: the raw hits.

- **What it adds to test_0052:**
  1. `.pyx` files: all 12 parse, 418 functions.
  2. PETSc collectives: petsc4py method names, and C names such as DMGetGlobalSection, MatAssembly* and SNESSolve.
  3. A `return`, `break` or `continue` under a rank-local guard, followed later in the same function by a collective. test_0052 sees this only inside loops. Raises are listed separately.
- **Validation:** it flags #1156's `_constrain_interior_multipliers_in_section` at baf11592 (the return at line 11845, before a collective at 11880). It does not flag it at 7f1c201f.
- **Development c2aa36b3, `.pyx`: 29 hits** (11 exits, 8 inside a guard, 10 raises). Triaged by reading:
  - **Every exit and inside hit is uniform:**
    - `_same_pattern` is an allreduce;
    - field names and `natural_bcs` are the same on every rank;
    - `n_ext_total` comes from an allgather;
    - the attributes are set on every rank.
  - **Latent, not a defect:** `_setup_discretisation` returns early on an xxhash of the rank's own `mesh.X.coords` (three solver classes). Probed at np 2 with a deform that moved only rank 1's nodes: Poisson, the vector projection and Stokes all re-solve. It is in the geometry inventory, under Charter §12.
  - **Defect: #1179.** The raise list led to `_build_velocity_nullspace_vector`. On a rank with no velocity nodes the mode reshape fails on that rank only. At np 8 with two empty ranks, MPICH aborts on mismatched Allreduces. The default `nullspace_rotations` reaches it on an annulus or sphere.
- **`.py` tree, the new rules:** 84 exits and 107 raises, not yet triaged. That pass comes before the exit rule joins test_0052.
