Title: Units: refuse an expression that mixes SI and non-dimensional factors before compiling or evaluating it

## Summary

Under the units system an expression can combine factors that come back in **different unit systems**. Some are SI, because they carry a dimensional constant (#771). Some are non-dimensional. Some have units borrowed from an unrelated variable (#843). Nothing flags this. The result is a wrong number, found only after the run, if at all.

This should never be possible silently. **A mixed-unit expression should be refused when it is built, compiled or evaluated, before any CPU time is spent.**

## The case that exposed it

The case is a 3-D micromorphic notch model under the units system. A yield indicator `2 * cm.viscosity * Einv2 / yield_stress` came out around 1e14 everywhere. Evaluated separately at one point:

| factor | evaluate returned |
|---|---|
| `stokes.constitutive_model.viscosity` | 8.20e22 (SI, Pa s) |
| the Drucker–Prager yield stress | 4.59e8 (SI, Pa) |
| `stokes.Unknowns.Einv2` | 3.83e-8 (neither non-dimensional nor 1/s) |

The same mixing in a solver's residual or Jacobian would put wrong physics into a run that converges.

## What is wanted

1. **One unit flavour per expression, checked.** At JIT compile (residual, Jacobian, aux), at `evaluate`, and at `Projection` setup, determine the dimensional status of every leaf: MeshVariable, UWexpression or constant. Refuse an expression that mixes SI-carrying and non-dimensional leaves, with a message naming the offending leaves. Do this before compiling or assembling anything.
2. **A cheap pre-flight check** that a model or solver can run (`solver.check_units()`, or automatically in `_setup_pointwise_functions`). It should report each term's dimensions and fail on an inconsistent sum (adding Pa to Pa/s, say).
3. `evaluate` should return the units of what it returns (a Pint quantity, or an explicit flag), so a caller can never silently divide an SI number by a scaled one.

Related: #771, #843, #763, #788 (all instances of the same boundary being crossed silently).
